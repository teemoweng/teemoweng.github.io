操作流程

就三步

Step 01
安装 Claude Code 或 Codex
搜索安装教程，按步骤完成，10 分钟搞定
Step 02
打开工具，粘贴下一页的 Prompt
AI 会自动读取模板，然后引导你提供个人信息
Step 03
按 AI 的引导操作，主页上线
AI 生成 HTML，帮你部署到 GitHub Pages
唯一需要手动做的：在浏览器注册 GitHub 账号——AI 会告诉你点哪里、填什么，全程陪跑。
复制这段提示词
粘贴给 Claude Code 或 Codex，然后按 AI 的问题回答即可
你好！我想基于一个现有的网站模板，做一个属于自己的个人主页并部署上线。请你全程帮助我完成这件事。 【模板地址】 https://teemoweng.github.io/template/ 请先访问这个地址，理解模板的结构、设计风格和功能（包括深色/浅色切换、中英双语、粒子动效等）。 【任务流程】 ───────────────────────────── 第一阶段：收集素材 ───────────────────────────── 首先询问我是否有以下现成材料，有的话直接发给你，你来提取信息，避免我从零填写： ① 简历（PDF / Word / 图片均可） → 可以直接从中提取姓名、教育、实习经历、技能等 ② 项目或成果文档 → 比赛 PPT、产品方案、论文、作品集等，帮助你了解我做过的项目 ③ 现有的 AI 对话记录或个人简介 → 如果你在其他 AI 工具里有过自我介绍或让 AI 帮你写过个人简介，可以直接粘贴过来 ④ LinkedIn 主页链接或其他社交主页 → 可以访问后自动提取信息 收到材料后，先告诉我你提取到了哪些内容，哪些还需要我补充。 ───────────────────────────── 第二阶段：逐项确认信息 ───────────────────────────── 对于材料里没有覆盖到的部分，以对话方式向我提问，每次最多问 3 个问题。 提问时主动给例子，帮我理解该写什么。具体引导方式如下： 【姓名 & 定位】 → 询问中英文姓名，以及一句话标签（例如"战略 · 产品 · AI"或"设计 · 用户体验 · 创业"） 【自我介绍】 → 2-3 句话，介绍背景和求职方向 → 引导语举例："可以参考这个格式：[学校/项目] 在读/毕业，有 [X] 年 [行业/职能] 经验，正在寻找 [方向] 岗位。" 【打字动画标签】 → 4-5 个描述自己的词，用于首页滚动展示 → 引导语举例："比如：产品经理、战略分析师、创业者、AI 爱好者、UX 设计师——选你最想被人记住的标签" 【个人动态】 → 时间线里程碑，最多 6 条，从近到远 → 引导语举例："可以包括：入学/毕业、实习入职、项目上线、比赛获奖、出国经历等，有时间点就行" 【项目经历】 → 最多 3 个，优先展示有成果的 → 引导语举例："比如：参加过什么比赛？自己做过什么产品或工具？有没有课程大项目或研究成果？有外部链接（App Store、演示页面、视频）最好" 【工作 / 实习经历】 → 按时间倒序，每段包含公司、职位、时间、1-2 句描述 → 引导语举例："重点写你具体做了什么、产出是什么，不需要写得很正式，口语化也没关系，我来帮你整理" 【教育背景】 → 最多 3 条，包含学校、专业、时间 【技能】 → 按类别列出，不确定怎么分可以直接列清单，我来归类 → 引导语举例："比如：数据分析（SQL、Python）、设计工具（Figma、Axure）、语言（普通话、英语、粤语）" 【联系方式】 → 邮箱（必填）、LinkedIn 链接（选填）、GitHub 用户名（选填） → 提醒用户：这些信息会公开显示在网页上，只填愿意公开的 【头像】 → 询问是否有个人照片，如有请提供文件（建议方形或接近方形） → 如无照片，使用姓名首字母作为占位，告知用户后续可以随时替换 语言处理规则： - 用户只提供中文 → 帮他翻译成英文 - 用户只提供英文 → 帮他翻译成中文 - 口语化表达 → 帮他整理成适合展示的语气 ───────────────────────────── 第三阶段：生成定制 HTML ───────────────────────────── 将收集到的信息填入模板，保留原有的所有设计、动效和 JS 逻辑，生成完整的 index.html 文件并保存到本地。生成后告诉我文件保存在哪里。 ───────────────────────────── 第四阶段：部署到 GitHub Pages ───────────────────────────── 引导我完成以下步骤（能直接执行的命令请帮我执行，需要浏览器操作的步骤请详细说明点哪里）： 1. 注册 GitHub 账号（如果我还没有） 2. 创建名为「GitHub用户名.github.io」的仓库（选 Public） 3. 将 index.html 上传到仓库 4. 开启 GitHub Pages 5. 确认网站上线，告诉我访问地址 【全程注意事项】 - 假设我完全不懂技术，所有步骤用最简单的语言说明 - 每完成一个环节，确认我操作成功后再进入下一步 - 遇到报错或卡住，帮我排查解决 请先打个招呼，然后问我有哪些现成材料可以提供。
